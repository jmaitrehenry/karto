Features

Everything you need to inspect a cluster

Karto gives you a focused, read-only window into your Kubernetes workloads — fast to open, easy to navigate.

Cluster Navigation

Switch between kubeconfig contexts instantly. Browse all namespaces or focus on one, and toggle between application and resource views.

Resource Browser

Search and filter workloads by name, kind, or status. Inspect readiness, images, labels, annotations, pods, services, and resource limits at a glance.

Live Log Streaming

Tail logs from any container in real time — with timestamp display, container selection, and configurable font size.

Events & YAML

Review recent Kubernetes events for any workload, and read rendered, syntax-highlighted YAML for supported resources.

Pod Terminal

Open an interactive exec session directly inside any pod — powered by xterm.js for a real terminal experience, without leaving the app.

Port Forwarding

Create and manage port forward sessions to any pod directly from the app. No kubectl commands needed — just point, click, and connect.

Use Cases

Built for inspection, not administration

Karto is the right tool when you need to understand what's happening in a cluster without touching anything.

  • Verify what is running in a namespace and whether it's healthy
  • Inspect workload health and related services end-to-end
  • Watch live logs during an active debugging session
  • Review recent Kubernetes events to find the root cause of an issue
  • Explore Custom Resources exposed by operators in your cluster
  • Read resource YAML without switching to the terminal
Non-goals

What Karto doesn't do

Keeping these off the table keeps the tool simple, safe, and fast to use.

  • Does not create, edit, or delete Kubernetes resources
  • Does not manage or create kubeconfig files or contexts
  • Does not bypass Kubernetes RBAC — visibility depends on your existing access
